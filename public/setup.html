Set up Live Trivia

Two one-time steps to make a fresh deployment playable. You can close this page afterwards and never come back to it.

0 Your setup key

This is the CRON_SECRET value from your Vercel environment variables. It is sent as a request header, so it never appears in the address bar or in your browser history, and it is not stored anywhere.

1 Create the tables

Applies the database schema. Safe to run more than once — it only ever creates what is missing and never drops or rewrites anything, so your players and scores are never at risk.

2 Add the first questions

Geography needs no API key — its answers come from public geographic datasets. This takes up to a minute. Run it again for Science or Current Events once ANTHROPIC_API_KEY is set.

Prefer a terminal? npm run migrate and npm run refresh -- --force do exactly the same thing from a clone of the repository. This page exists so that neither is required.
